# Support

Aegisora is an open-source runtime security and governance layer for autonomous AI agents.

## Questions and Discussion

Use GitHub Discussions for architecture questions, implementation questions, ideas, design proposals, and community collaboration.

https://github.com/aegisora-ai/aegisora/discussions

## Bugs

Use the structured GitHub bug report form for reproducible software problems.

Include the Aegisora version or commit, environment, reproduction steps, expected behavior, actual behavior, and relevant logs.

## Security

Do not publish sensitive vulnerabilities in public issues, discussions, or pull requests.

Use SECURITY.md and the project's private security reporting channel.

https://github.com/aegisora-ai/aegisora/blob/main/SECURITY.md

## Feature Requests

Use the feature request issue form for new capabilities.

For large architectural proposals, use GitHub Discussions before implementation.

## Contributions

Start with CONTRIBUTING.md and choose a clearly scoped issue.

Good contribution paths include documentation, testing, developer experience, security research, agent integrations, MCP integrations, and benchmarks.

## Community Standard

Please read CODE_OF_CONDUCT.md and keep technical discussions evidence-led, constructive, and focused on the problem.
