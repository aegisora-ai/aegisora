# Support

Aegisora is an open-source runtime security and governance layer for autonomous AI agents.

## Questions and Discussion

Use GitHub Discussions for architecture questions, implementation questions, technical proposals, and community collaboration.

https://github.com/aegisora-ai/aegisora/discussions

## Bugs

Use the GitHub issue forms for reproducible software problems.

Include the version or commit, environment, reproduction steps, expected behavior, actual behavior, and relevant logs.

## Security

Do not publish sensitive vulnerabilities in public issues or discussions.

Follow SECURITY.md for responsible disclosure.

https://github.com/aegisora-ai/aegisora/blob/main/SECURITY.md

## Contributions

Start with CONTRIBUTING.md and choose a clearly scoped issue.

Useful contribution areas include runtime security, agent integrations, MCP, testing, benchmarks, documentation, and developer experience.

## Community

Read CODE_OF_CONDUCT.md and keep technical discussions constructive and evidence-led.
