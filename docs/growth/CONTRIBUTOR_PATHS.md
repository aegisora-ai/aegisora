# Aegisora Contributor Paths

## First Contribution

Start with documentation, tests, reproducible examples, small fixes, or developer experience improvements.

## Security Research

Explore runtime enforcement bypass, policy bypass, identity confusion, authorization replay, tool abuse, approval integrity, and evidence integrity.

Sensitive vulnerabilities must follow SECURITY.md.

## Agent Integrations

Useful paths include LangGraph, MCP, model providers, tool execution, and observability.

## Testing and Benchmarks

Contribute adversarial cases, regression tests, policy fixtures, latency benchmarks, and security benchmarks.

## Documentation

Improve architecture, quickstarts, deployment, threat scenarios, integration guides, and troubleshooting.

## Developer Experience

Improve local setup, examples, CLI tooling, test helpers, and CI.

## Contribution Standard

Prefer small, reviewable, reproducible changes.
