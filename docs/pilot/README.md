# Aegisora pilot program

Test Aegisora on a real agent workflow in your company, free of charge, and tell us honestly whether it is worth paying for.

## What you get

- Help installing Aegisora next to one AI agent and one tool (Gmail is the first supported connector).
- Every agent action decided before it runs: ALLOW, ESCALATE to a named human, or BLOCK.
- A weekly summary of what the agent tried to do and what Aegisora decided.
- Direct access to the maintainers.

## What we ask

- One agent, one workflow, 4 to 6 weeks.
- One technical contact and one approver.
- A 30-minute review every two weeks and a short feedback survey at the end (see `FEEDBACK-SURVEY.md`).
- No production secrets or customer data are required. Start with a test mailbox.

## Timeline

| Week | What happens |
| --- | --- |
| 0 | Kickoff call, pick the workflow, agree success metrics |
| 1 | Install and first governed actions |
| 2-5 | Operate, collect numbers, fix blockers |
| 6 | Review results and decide: stop, continue, or move to a paid plan |

## Success metrics we measure together

- Number of agent actions governed, blocked and escalated
- Time an approver needs to decide
- Actions that should have been stopped and were
- Setup time from start to first governed action
- Whether your team would continue and what they would pay

## Terms

The pilot runs under a short written agreement. A template is in `PILOT-AGREEMENT-TEMPLATE.md`. Your company name and results are never published without your written consent.

## Apply

Apply at https://www.aegisora.org/pilot. Please do not post company details in public issues.

Aegisora is pre-release software. See the Limits section of the main README and `docs/launch-readiness.md` for what is and is not proven.
