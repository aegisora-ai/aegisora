# Aegisora Mobile - API Contract
Geliþtirme sýrasýnda beklenen backend endpoint'leri. Mevcut backend'de farklýysa `client.ts` içinde adapte edilecektir.
- `GET /api/approvals`
- `GET /api/approvals/:id`
- `POST /api/approvals/:id/approve`
- `POST /api/approvals/:id/reject`
- `POST /api/agents/:id/pause`
